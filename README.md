# git-learning

个人 Git / GitHub 练习仓库。

## 目录

- `git_firstleraning/` — 早期练习目录（当前为空。Git 不追踪空文件夹，放入文件后才会出现在版本库中）

## 常用命令

```bash
git status                  # 查看当前状态
git add .                   # 暂存所有改动
git commit -m "提交说明"     # 提交到本地仓库
git log --oneline           # 查看提交历史
git remote -v               # 查看远程地址
git push                    # 推送到 GitHub
```

## 分支

默认分支为 `main`。
